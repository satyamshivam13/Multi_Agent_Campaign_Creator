**RunMetadata model** (D-03, D-04 impl):
  - `run_id`: RunID (the run identifier)
  - `start_time`: datetime (workflow start, UTC)
  - `end_time`: Optional[datetime] (None until workflow completes)
  - `status`: str (enum-like: "pending", "running", "success", "failed", "rerun" per D-07)

Import `secrets` and `secrets.token_hex(3)` for the random suffix (generates 6 lowercase hex chars, trim to 5 for display).

- RunMetadata.status must be one of: "pending", "running", "success", "failed"

**File: src/runtime/run_store.py**

Implement `RunStore` class with these methods:

1. **`__init__(db_path: Path = None)`**
   - Default: `db_path = settings.output_dir / "runs.db"`
   - Store `self.db_path = Path(db_path)`
   - Call `self.init_db()` to create schema if needed

2. **`init_db() -> None`** (idempotent schema initialization)
   - Connect to SQLite, create schema if not exists
   - Create `runs` table with columns:
     - `run_id` (TEXT PRIMARY KEY) — from RunID.value
     - `start_time` (TIMESTAMP) — datetime ISO format
     - `end_time` (TIMESTAMP NULL)
     - `status` (TEXT) — "pending", "running", "success", "failed"
     - `retry_count` (INTEGER) — default 0
     - `terminal_failure_reason` (TEXT NULL)
     - `parent_run_id` (TEXT NULL, FOREIGN KEY runs.run_id)
     - `config_snapshot` (JSON) — serialized CampaignRequest
     - `created_at` (TIMESTAMP) — INSERT timestamp
   - Create `artifacts` table with columns:
     - `id` (INTEGER PRIMARY KEY AUTOINCREMENT)
     - `run_id` (TEXT, FOREIGN KEY runs.run_id)
     - `artifact_path` (TEXT) — relative path under output_dir
     - `content_hash` (TEXT) — SHA256 hex digest of file contents
     - `saved_at` (TIMESTAMP)
   - Create indices on `runs.run_id`, `runs.parent_run_id`, `artifacts.run_id`

3. **`create_run(run_id: RunID, request: CampaignRequest, parent_run_id: Optional[RunID] = None) -> RunMetadata`**
   - Serialize request to JSON via `request.model_dump()`
   - INSERT into runs: (run_id.value, start_time=now, status="pending", retry_count=0, config_snapshot=request_json, parent_run_id=parent_run_id.value if parent_run_id else None)
   - COMMIT
   - RETURN RunMetadata object with status="pending"

4. **`update_run_status(run_id: RunID, status: str, end_time: Optional[datetime] = None, failure_reason: Optional[str] = None, retry_count: Optional[int] = None) -> RunMetadata`**
   - UPDATE runs WHERE run_id=? SET status=?, end_time=?, terminal_failure_reason=?, retry_count=?
   - COMMIT
   - RETURN updated RunMetadata

5. **`record_artifact(run_id: RunID, artifact_path: str, content_hash: str) -> None`**
   - INSERT into artifacts: (run_id, artifact_path, content_hash, saved_at=now)
   - COMMIT

6. **`get_run(run_id: RunID) -> Optional[RunMetadata]`**
   - SELECT * FROM runs WHERE run_id=?
   - SELECT * FROM artifacts WHERE run_id=? (join results)
   - BUILD RunMetadata object from row + artifacts
   - RETURN RunMetadata or None if not found

7. **`get_runs_by_parent(parent_run_id: RunID) -> list[RunMetadata]`**
   - SELECT * FROM runs WHERE parent_run_id=?
   - Useful for audit trail (rerun chain discovery)

**Error handling:**
- Catch sqlite3.IntegrityError and re-raise as ValueError with user message
- Close connection in __del__ or use context manager pattern (optional but recommended)

| T-01-004 | Repudiation | run status mutations | accept | SQLite has no audit log; acceptable for single-user CLI tool (add created_at/updated_at if needed later) |
